# Paseo 展示文案

## 原则

- 标题陈述当前状态，说明只补充必要原因或下一步。避免重复安全声明和实现术语。
- 网页状态、Paseo 跟踪、内容同步分别表达。扩展在线不等于同步正常，跟踪失败不等于网页执行失败。
- 区分事实与未确认结果。未读到送达凭据不能称“未发送”；未确认停止不能称“已停止”；保存请求失败不能断言远端未保存。
- “本轮已结束”仅指这一轮，不保证远程工具或后台任务全部结束。工具结果未确认时明确说明，不根据回答猜测成功。
- 授权需用户选择。按钮显示网页原名，不将 Chrome 的 `Allow` 改称“允许一次”；授权框关闭不代表已批准。
- 只修订插件文案，不改写回答、公开思考摘要、来源名、工具名或网页提示。脱敏/截断的提示不再标为“原文”。
- 正常状态不堆叠说明；错误保留诊断码，恢复提示不承诺内容已在 Paseo 显示。

## 关键示例

| 场景 | 文案 |
| --- | --- |
| 并发排队 | 排队第 2 位 · 尚未发送 |
| 发送处理中 | 正在发送，等待送达确认 |
| 送达结果不明 | 已尝试发送，送达未确认 |
| 网页消息暂不可读 | 本轮消息暂不可读 |
| 等待用户授权 | 等待授权 |
| 网页回答未确认结束 | 最终回答尚未确认 |
| 本轮完成 | 本轮已结束 |
| 本地跟踪失败 | 本轮跟踪中断 |
| 授权点击未获确认 | 授权操作未确认 |
| 网页授权框消失 | 网页授权框已关闭 |
| 工具无独立终态 | 本轮已结束；网页未单独确认此调用的结果。 |

共享状态词及错误说明在 `shared/ui-copy.mjs`；新旧状态卡和无卡片客户端复用同一状态词。设置页不再显示硬编码旧版本号，也不宣称正文逐字流式回传。

候选版本：alpha.4.27。仅插件展示变更，扩展仍为 0.2.32。部署需重载插件；本次不要求重载扩展或刷新 ChatGPT 页面。新文案不会自动重写已保存的历史通知或工具详情。
